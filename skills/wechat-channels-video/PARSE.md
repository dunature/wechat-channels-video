# PARSE.md — 视频号解析钩子（可插拔）

本 skill **不把解析硬编码到某一实现**（例如不强制 watchVideo）。下载完成后，按下面约定选择解析后端。

## 输入

| 字段 | 说明 |
|------|------|
| `video_path` | 本地下载得到的视频绝对路径 |
| `url` | 原始分享链接（可选，便于引用） |
| `locale` | 默认 `zh-CN`：摘要用中文 |
| `depth` | `brief`（默认）或 `detailed` |

## 输出（建议结构）

用中文交付，可按视频内容裁剪小节：

1. **一句话结论**
2. **大纲**（时间线或章节）
3. **关键论点 / 框架 / 工具名**
4. **可操作要点**（如何选、怎么做）
5. **未覆盖 / 需自查**（可选）

不要把原始视频或 cookie 贴进输出。

## 钩子优先级（从上到下，命中即用）

1. **环境变量覆盖**  
   - `WECHAT_CHANNELS_PARSE_CMD`：可执行命令模板。  
   - 占位符：`{video_path}`、`{url}`、`{locale}`、`{depth}`。  
   - 示例：  
     `WECHAT_CHANNELS_PARSE_CMD='my-transcribe --file {video_path} --lang {locale}'`

2. **同目录可选脚本**  
   - 若存在可执行文件 `scripts/parse.sh`，调用：  
     `bash scripts/parse.sh --video "$video_path" [--url "$url"] [--depth brief|detailed]`  
   - **本仓库默认不提供** `parse.sh`，由使用者按需添加（保持解析可插拔）。

3. **Agent 原生多模态**  
   - 把视频文件交给当前 agent 可用的「看视频 / 附件理解」能力。  
   - Prompt 建议：  
     - 「详细描述视频中发生的内容」  
     - 「用中文输出结构化摘要：大纲、关键论点、框架/工具、可操作结论」

4. **降级**  
   - 若无法读视频：说明原因，保留 `video_path`，请用户本地观看或自行接入 ASR。

## 实现注意

- 解析失败不应删除已下载文件。
- 大文件优先在文件所在机器上解析，避免无谓拷贝。
- 若视频仅在远端机器，按 agent 能力拷贝后再解析（例如箱内多模态）。
